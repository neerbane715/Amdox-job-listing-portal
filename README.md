Amdox – Job Listing Portal

A modern job listing portal connecting job seekers and employers, built with vanilla JavaScript and Firebase.




🌟 Overview

Amdox is a full-stack job portal that simplifies hiring and job searching with role-based dashboards, real-time updates, and a modern UI.

✨ Features
👤 Job Seekers

Smart job search with filters

Profile & resume management

One-click job applications

Real-time application tracking

🏢 Employers

Create & manage job postings

View applicants and resumes

Company profile management

Application dashboard & notifications

⚙️ Platform

Dual authentication (Candidate/Employer)

Role-based access control

Responsive, modern UI with animations

Real-time data using Firebase

Secure resume storage

🛠️ Tech Stack

Frontend

HTML5, CSS3 (Glassmorphism, animations)

Vanilla JavaScript (ES6+)

Backend & Services

Firebase Authentication

Firebase Firestore

Firebase Storage

Firebase Analytics

🚀 Getting Started

Clone the repo

git clone https://github.com/neerbane715/Amdox-job-listing-portal.git
cd Amdox


Set up Firebase

Enable Auth, Firestore, Storage

Update firebase-config.js

Run

Open Frontend/index.html
or

cd Frontend
python -m http.server 8000
